# 한밤 바닷가 모닥불

별이 쏟아지는 겨울 밤바다에서 모닥불 앞에 모여 쉬어 가는 3D 힐링 공간이에요.

- 불멍, 마시멜로·고구마 굽고 한 입씩 먹기
- 모래에 걱정 쓰기 (파도가 지워 줘요), 모래에 그림 그리기
- 모닥불 5개 · 통나무 자리 48개 · 돗자리 35장
- 220m 해변 산책, 누워서 별 보기, 별똥별에 소원 빌기
- 같은 페이지에 들어온 사람들이 실시간으로 함께 보여요 (Supabase Realtime)

## 구성
- `index.html` 한 파일로 동작해요. 빌드 과정이 없어요.
- 3D: three.js r128 (cdnjs)
- 실시간 함께 보기: Supabase Realtime Presence + Broadcast (`balance-game` 프로젝트, 테이블 사용 안 함)
- 페이지에 들어 있는 키는 공개용(publishable) 키예요.

## 배포
Vercel에서 이 저장소를 Import 하면 별도 설정 없이 정적 사이트로 배포돼요.
